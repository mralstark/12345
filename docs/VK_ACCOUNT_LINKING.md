# Один кабинет в Telegram и ВКонтакте

Повторная регистрация участникам с существующим Telegram-кабинетом не нужна.
Связываются способы входа с одним `User` и `Member`: роли, регион участия,
задания, Академия, награды и история не копируются и не обнуляются.

## Подключение по коду

1. Открыть https://vk.ru/app54848740 под своим VK-аккаунтом.
2. Нажать «У меня уже есть кабинет в Telegram» → «Получить код подключения».
3. Открыть свой кабинет в Telegram. В «Профиле» выбрать «Способы входа» →
   «Ввести код из ВКонтакте». Если включены и Mini App, и браузерный VK ID,
   сначала выбрать «Приложение ВКонтакте».
4. Ввести код, проверить свой VK ID и явно подтвердить подключение.
5. Вернуться в VK и нажать «Открыть мой кабинет».

После этого обычная ссылка VK открывает тот же кабинет; подтверждать каждый
вход в Telegram не нужно. Доступ к Telegram нужен однократно для привязки.
Подключение по одноразовой ссылке из Telegram тоже остаётся доступным.

## Ограничения и безопасность

- Код действует 10 минут, одноразовый, хранится только в виде SHA-256.
  Новый код для того же VK-аккаунта отменяет предыдущий.
- Создание кода требует подписанного VK-запуска с проверкой приложения и срока.
  Код привязан к этой VK-личности; VK ID из тела запроса не принимается.
- Просмотр и подтверждение требуют подписанного Telegram initData не старше
  пяти минут, правильного Origin и действующего собственного кабинета.
  Старые веб-сессии, режим «Войти как…» и отключённые аккаунты не подходят.
- Код нельзя отправлять другим людям или подтверждать по чужой просьбе.
  Вход по совпадению ФИО, контакта или username не предоставляется.
- Один VK-аккаунт подключается к одному кабинету. Уже одобренные отдельные
  кабинеты автоматически не объединяются: нужен разбор владельцем сервиса.
- Если из этого VK уже отправлена вторая анкета, при явном подтверждении
  подключения она закрывается с причиной «Владелец подключил существующий
  кабинет Telegram»; анкета сохраняется в истории. Нового пользователя нет.
- Отключение VK выполняется в свежем Telegram-кабинете, сразу отзывает VK-доступ
  и сохраняет вход через Telegram.

Схема БД и переменные окружения не меняются. Используются существующие
`external_identities` и `oauth_login_attempts` с отдельным назначением `mini_pair`.
Проверка заявки, создание новой заявки и привязка синхронизируются блокировкой
VK-личности; уникальные ограничения не допускают перепривязку через гонку.
Коды не передаются в URL, журналы запросов или локальное хранилище браузера.
Процесс подтверждения через Telegram Mini App не требует исходящего запроса
с сервера к Telegram Bot API.
