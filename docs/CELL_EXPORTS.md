# Выгрузки вузовских ячеек

Перед обновлённым API выполнить `python -m scripts.migrate_cell_status`.
Миграция аддитивная и повторяемая; старые записи имеют статус «Не указан».
Новая колонка не содержит персональных данных, состав защищённых полей и ключи
шифрования не меняются. При откате старый код игнорирует новую колонку.

Руководитель региона и superuser заполняют статус в карточке ячейки по
существующим правам изменения региона. Координаторы и федеральный руководитель
могут просматривать и экспортировать доступные регионы. Руководитель ячейки
и обычный участник не получают массовые выгрузки.

В разделе ячеек доступны четыре Excel-выгрузки: список, численность и состав,
финансы, всё вместе. Область — текущий регион либо все доступные регионы.
Контакты руководителя берутся из существующего аккаунта и связанной карточки;
отсутствующие контакты остаются пустыми. Численность — активный состав ячейки.
Финансы — за всё время, только явно привязанные операции; региональные суммы
не распределяются по ячейкам. Деньги переводятся из копеек в рубли.

Файлы хранятся зашифрованными и скачиваются по ссылкам на 10 минут с повторной
проверкой прав. Строки Excel не исполняются как формулы. Выгрузки ограничены
50 регионами, 2000 ячейками, 20000 участниками и 20000 операциями за запрос;
при превышении требуется выбрать отдельный регион.

Самостоятельная вкладка «ВУЗы» скрыта; API, каталог и регистрация сохранены.
Основной текст использует локальные WOFF2 Roboto (кириллица и латиница,
400/500/700), лицензия OFL рядом со шрифтом; Forum заголовков сохранён.
