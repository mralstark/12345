# VK Mini App

ВКонтакте, Telegram и веб-кабинет используют общий API, пользователей и права.
Приложение VK: https://vk.ru/app54848740. Дополнительный сайт или копия базы
для него не нужны. VK ID OAuth — отдельная, необязательная интеграция.

## Настройки

В настройках Mini App укажите действующий HTTPS-адрес кабинета для мобильного
приложения, мобильной и настольной версий сайта. Режим разработки выключен.
На текущем сервере адрес: `https://lk.31-129-98-217.sslip.io`.

В серверном `.env` задайте `VK_MINI_APP_ID=54848740` и
`VK_MINI_APP_SECRET` — защищённый ключ именно этого приложения. Ключ не попадает
в Git, браузер, конфигурационный API или журналы. Файл доступен только root и
группе сервиса, режим 0640. После изменения настроек перезапустите API.
Пустые обе переменные выключают интеграцию; неполная пара блокирует запуск.
`VK_ID_CLIENT_ID` для Mini App заполнять не требуется.

## Вход и регистрация

Откройте приложение внутри VK. Сервер проверяет HMAC подпись параметров запуска,
ID приложения, ID пользователя и время выдачи (до часа, допустимое опережение
часов — минута). Просроченные параметры требуют повторного открытия приложения.
Параметры передаются в заголовке `Authorization: vkma …`; cookies третьей
стороны для входа в iframe не нужны. Не публикуйте подписанные ссылки запуска.

Новый участник разрешает VK передать номер телефона, заполняет анкету и ожидает
одобрения руководителя. Сервер проверяет подпись исходного номера и привязку
подписи к этому VK-пользователю. Это подтверждение ответа провайдера; отдельный
флаг `is_verified` не подписан и не используется сервером как доказательство
проверки SMS. Номер и имя не дают доступа к существующему кабинету или роли.
Отказ от передачи номера оставляет форму доступной для повторной попытки.

## Уже есть Telegram-кабинет

Откройте его в Telegram и выберите «Способы входа» → «Подключить ВКонтакте».
Ссылка действует 10 минут, используется один раз и хранится на сервере только
как хеш. Перед подтверждением VK показывает имя подключаемого кабинета.
Ссылку нужно открывать под собственным VK-аккаунтом и не пересылать другим.
Создание и отключение привязки требуют свежего входа через Telegram (до 5 минут)
и недоступны в режиме «Войти как…».

Совпадение телефона или имени никогда не объединяет пользователей автоматически.
Если анкета VK уже была отправлена до подключения Telegram-кабинета, её нельзя
одобрить повторно: руководитель может отклонить устаревшую заявку. Действующий
кабинет, роли и история при подключении сохраняются. Идентификаторы Mini App
и VK ID OAuth находятся в разных пространствах; они не взаимозаменяемы.

## Проверка выпуска

1. Проверить вход нового пользователя на мобильном VK и на vk.ru с компьютера.
2. Отменить передачу телефона, повторить и отправить анкету; проверить одобрение.
3. Подключить существующий Telegram-кабинет и проверить сохранение ролей.
4. Повторно открыть одноразовую ссылку — подключение должно быть отклонено.
5. Проверить скачивание отчёта: нативный загрузчик VK, если поддерживается;
   при ошибке доступна явная ссылка открытия файла в браузере.
6. Проверить вход через Telegram и прежний браузерный вход.

Bridge 3.0.2 поставляется локально с лицензией и хешами в `webapp/vendor/`.
CSP разрешает встраивание только перечисленным доменам Telegram и VK.
Неподписанные параметры запуска, неизвестный ID приложения и неактивный
пользователь отклоняются. На каждом API-запросе действуют текущие права сервера.
