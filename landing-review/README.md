# Страница-шлюз в личный кабинет

Собрана заново на реальной фотографии (`source/original.jpg`, 604×367).
Сгенерированных изображений и видео на странице нет.

## Почему фото подано как отпечаток, а не как полноэкранный фон

Оригинал — низкоразрешённый скан старого печатного оттиска. При увеличении
детали рассыпаются (проверено на кропах ×4: лица не читаются). Поэтому:

- снимок никогда не растягивается на весь экран, максимум 880px (≈1.5×);
- он подан как архивный отпечаток: тонкая золотая рамка, уголки, подпись;
- фоном страницы служит он же, но сильно размытый и затемнённый, — мягкость
  там намеренная, разрешение не выдаёт себя.

Обработка (`ffmpeg`, без домысливания деталей): обесцвечивание, контраст 1.08,
lanczos ×2, лёгкий unsharp. Тонировка в тёплый тон сделана в CSS, файл остаётся
близким к оригиналу.

## Прокрутка

Герой закреплён на 520vh, прогресс 0..1 пишется в `--p`, остальное считает CSS.
Три полосы текста: 0.00–0.26, 0.34–0.62, 0.70–1.00. Снимок выходит из тени,
затем к финалу вокруг него дорисовывается рамка и появляется кнопка входа.
Текст никогда не лежит поверх фотографии — только на холсте под ней.

## Проверено

- flick-тест: полосы держатся 7/6/8 щелчков по 120px, плато 92/82/108vh,
  ни одна не проскакивает при 360px;
- контраст: основной текст 15.3:1 на холсте (10.8:1 по самому светлому
  возможному пикселю фона), вторичный 6.8:1 (4.8:1), кнопка 9.8:1;
- горизонтальной прокрутки нет (scrollWidth == innerWidth);
- страница полностью работает без JavaScript: снимок в финальном состоянии,
  заголовок и кнопка входа на месте;
- мобильный статичный герой (375×812) и короткое окно (1280×540) без обрезаний;
- консоль чистая.

Замечание: em-dash в тексте оставлены сознательно — это нормальная русская
типографика, а не признак машинного текста.

Страница отдаётся FastAPI по адресу `/welcome` (см. `api/main.py`).
